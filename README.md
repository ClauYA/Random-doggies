# Random-doggies - Random Dog Generator

A fun web app that generates random dog images with humorous mood descriptions, working to be random too.

## About

Rocky's Moods is a playful random dog generator that fetches random dog images and pairs them with funny mood descriptions. Perfect for when you need a quick dose of serotonin or just want to see what kind of mischief Rocky is getting into today.

## Features

- **Random Dog Images**: Fetches random dog photos on each click
- **Mood Generator**: Displays humorous mood descriptions
- **One-Click Refresh**: Simple button to get a new dog and mood
- **Responsive Design**: Works great on mobile and desktop
- **No Dependencies**: Pure HTML, CSS, and JavaScript

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Dog API integration
- Normalize.css
